# Task 21 Installation Guide

## Quick Start (3 Minutes)

### 1. Create Environment
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run Demo
```bash
python demo.py
```
