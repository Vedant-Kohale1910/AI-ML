  PlaceMux - Phase 2 (25 tasks)  ·  START HERE
==================================================================

This project is 25 connected tasks that build an AI/ML placement
marketplace: matching, ranking, recommendations, parsing, fairness,
MLOps, and a live-monitoring "go-live". Each task is its own runnable
folder, but they tell one story from Task 1 to Task 25.

You only need to do TWO things: install Python once, then run setup.

------------------------------------------------------------------
STEP 0 — Install Python (one time)
------------------------------------------------------------------
  - Download Python 3.11 or newer:  https://www.python.org/downloads/
  - IMPORTANT (Windows): during install, TICK the box that says
    "Add Python to PATH". If you skip it, nothing below will work.

------------------------------------------------------------------
STEP 1 — Unzip
------------------------------------------------------------------
  - Unzip this file somewhere simple, e.g.  C:\PlaceMux
  - Open the folder named:  Phase 2 complete Project
  - (You are reading START_HERE.txt from inside that folder.)


==================================================================
  WINDOWS  (PowerShell)
==================================================================

STEP 2 — Open a terminal in this folder
  - Click the folder's address bar, type:  powershell
  - Press Enter. A blue terminal opens, already in the right place.

STEP 3 — Set everything up (one command, takes a few minutes)

    powershell -ExecutionPolicy Bypass -File setup.ps1

  This creates an isolated .venv and installs all dependencies.

STEP 4 — Run a task's demo (prints real metrics)

    .\run_task.ps1 1

  Change the number to run any task 1-25. Examples:
    .\run_task.ps1 3
    .\run_task.ps1 17

STEP 5 — Or start a task's live API (tasks 1-17 only)

    .\run_task.ps1 3 serve

  Then open the link it prints (e.g. http://localhost:8003/docs)
  in your browser and click through the endpoints. Ctrl+C to stop.


==================================================================
  MAC / LINUX  (Terminal)
==================================================================

  cd "Phase 2 complete Project"
  bash setup.sh
  bash run_task.sh 1          # run Task 1's demo
  bash run_task.sh 3 serve    # start Task 3's API, open the printed URL

==================================================================
  IF SOMETHING GOES WRONG
==================================================================
  "running scripts is disabled on this system"
     -> Use the exact setup line with -ExecutionPolicy Bypass:
        powershell -ExecutionPolicy Bypass -File setup.ps1

  "python is not recognized"
     -> Python isn't on PATH. Reinstall Python and TICK
        "Add Python to PATH", then open a NEW PowerShell window.

  Weird checkmark / symbol errors
     -> Already handled; the scripts force UTF-8 output. Just re-run.

  Install is slow the first time
     -> Normal. It downloads packages once into .venv, then it's fast.
