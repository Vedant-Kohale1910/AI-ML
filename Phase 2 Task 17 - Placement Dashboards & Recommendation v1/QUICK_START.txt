================================================================================
WHAT THE SYSTEM DOES
================================================================================

INPUT:
  - Student profile (skills, experience, assessment score)
  - Job description (required skills, years needed)

PROCESS:
  1. Parse student resume → extract structured data
  2. Parse job description → extract requirements
  3. Calculate recommendation score using 5 features:
     - Skill match (50% weight)
     - Assessment score (20%)
     - Experience (15%)
     - Certifications (10%)
     - Education (5%)
  4. Generate explanations (why this job was recommended)
  5. Rank jobs by score (TIER_A/B/C/D)

OUTPUT:
  Top 5 recommended jobs with:
  - Recommendation score (0-100%)
  - Matched skills
  - Missing skills
  - Plain-English explanation
