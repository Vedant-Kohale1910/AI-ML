# Task 2 — Pre-Project Feature Scope & Profiling
**PlaceMux AI/ML Developer · Phase 1 Industry Immersion**

## Problem Statement
> Predict whether a credit card transaction is fraudulent using transaction-level and account-level features available at the time of the transaction.

| Item | Value |
|---|---|
| Target | `is_fraud` (0=legit, 1=fraud) |
| Task Type | Binary Classification |
| Success Metric | F1-Score + Precision-Recall AUC |
| Dataset | 1500 rows, 16 columns |
| Features Retained | 13 (after removing 2 leakage/ID columns) |

## Dataset
`data/credit_fraud_dataset.csv` — Synthetic credit card transaction data with realistic fraud patterns.

## Installation
